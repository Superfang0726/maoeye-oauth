MaoEye 隱私權政策

Privacy Policy · 最後更新 2026-10-17

適用範圍

MaoEye 是作者自行開發、自行執行的個人工具，只存取作者本人的 Gmail 帳號，不提供給其他使用者。

存取的資料

MaoEye 透過 Google 的 gmail.modify 權限，只做兩件事：讀取來自單一特定寄件者的郵件，以及在這些郵件上加 Gmail 標籤。它不會寄信、刪信，也不會讀取通訊錄或其他 Google 服務的資料。

資料的使用與保存

  • 郵件內容只用來產生作者自己使用的結構化資料，保存在作者自己的伺服器上。
  • 不出售、不出租，也不提供給任何第三方做廣告或其他用途。
  • 為了把郵件文字整理成結構化資料，郵件正文（已移除連結與聯絡資訊）可能會送到作者使用的 AI 服務處理，僅供這個用途。
  • OAuth 憑證只存在作者的伺服器上，不會公開。

Google API 服務使用者資料政策

MaoEye 使用從 Google API 取得的資料時，遵守 Google API Services User Data Policy，包括其中的 Limited Use 規定。

撤銷存取權

可隨時在 Google 帳戶的第三方存取權 移除 MaoEye 的存取權。

English summary

MaoEye is a personal tool used only with its author's own Gmail account. Using the gmail.modify scope, it reads emails from one specific sender and adds labels to them; it never sends or deletes email. Data is stored on the author's own server and is not sold or shared with third parties. Email text (with links and contact details removed) may be processed by an AI service solely to extract structured data for the author. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
